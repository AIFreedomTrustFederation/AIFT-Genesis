# Roadmap

## Phase 1: Genesis Pack

Create the canonical repository structure, doctrine, templates, manifests, schemas, examples, and generator specifications.

## Phase 2: Genesis Generator

Build commands that instantiate local-first trust workspaces from Genesis templates.

Example commands:

```text
genesis trust init
genesis business init
genesis community init
genesis repository init
```

## Phase 3: Federation Console Integration

Make the AIFT-OS Federation Console the personal workspace that can initialize, inspect, edit, and operate a local trust seed through governed actions.

Integrate the upstream-derived `mobox` repository separately as a Windows application and game compatibility runtime. It does not own the Federation Console, schemas, governance, or world renderer.

## Phase 4: Forge Integration

Make AIFT Forge the repository, build, package, issue, release, and federation engine for trust workspaces.

## Phase 5: Living Federation World

Publish the engine-independent `aift.world.v1` snapshot and delta protocols. Map trusts, projects, missions, repositories, businesses, runtimes, and communities around each user's Green Zone. The Mysterion Cortex client consumes this protocol with continuous spatial navigation and semantic levels of detail.

## Phase 6: Federation Protocols

Define safe, voluntary synchronization between local trusts and shared Federation layers.
