## Proposed integration

- Tree node identity, type and parent/relation IDs must remain source-backed and testable.
- Roots are repository/provenance sources; trunk tested integration; branches real systems; leaves knowledge; flowers developing verified work; fruits delivered products with working destinations.
- Prototype OS interfaces must carry source manifest digest, contract version, error state and provenance, not phantom progress.
- Application capability manifests, mobile device profiles or agent permissions must not silently become constitutional grants.
- Any schema change needs producer/consumer compatibility tests and separate approval where governance, trust or identity is affected.
